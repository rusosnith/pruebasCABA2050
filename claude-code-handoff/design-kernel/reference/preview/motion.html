Reglas
  • Default easing es --ease-out. Entradas y la mayoría de UI.
  • --ease-in-out sólo para movimientos largos simétricos (sheets, modales).
  • --ease-in sólo en salidas (cierre). Nunca para entradas — se siente lento.
  • Hovers cambian background-color y color, jamás transform: scale.
  • Honrá prefers-reduced-motion: corta animaciones a 0ms cuando esté activo.
