ARIA — checklist por componente
  • Combobox (autocomplete de dirección): role=combobox + aria-expanded + aria-activedescendant.
  • Tabs: role=tab + aria-selected. Flechas izquierda/derecha cambian.
  • Bottom sheet / modal: role=dialog + aria-modal=true + focus trap + Esc cierra.
  • Stepper: aria-current=step en el paso activo.
  • Toast / notif: role=status (info) o role=alert (error).
  • Loading: aria-busy=true en el contenedor.
  • Iconos solitarios: aria-label obligatorio.
  • Decorativos: aria-hidden=true.
